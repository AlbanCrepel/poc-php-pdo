# PHP boilerplate

```bash
php -m | grep -i sqlite # `pdo_sqlite` and `sqlite3` should appear
# Run the website on a local web server (http://localhost:8085)
php -S localhost:8085 -t . # launch the web server
```

Pages available:
- http://localhost:8085/
- http://localhost:8085/posts.php
- http://localhost:8085/?url=about
